Intelligence that doesn't wait for instructions.

Unbidden is an engineering agent you install like a CLI. It enters a repository it has never seen, runs the team's own checks in an offline sandbox, decides what is worth improving, makes the change, and measures whether the system actually got better. Then it says so at the level of evidence it reached, and not one level higher.

Source Evidence Architecture

The loop, with no one steering

Each step is a job in a local queue. Each decision is recorded with its reason, and every byte that leaves the machine is kept.

observestack, CI, services, metrics, logs, a world model with provenance
decideexpected value per opportunity; declines what the team's CI already rules out
investigateproperty-based probes, read-only investigations
forgebuilds missing readers, judged by an oracle with no model
labcandidate vs base, the team's tests, CI parity, statistics
propose · operatePRs with evidence; deploy, judge, roll back under a mandate

Meta models, each where it belongs

Muse Spark 1.3 · remote

Heavy work on content allowed to leave: property tests, fixes, workloads, adapters. Private code reaches it only after the privacy bridge renames every non-public word.

Muse Glimmer · local

The only model that sees secrets, logs or production data. Chosen to fit the machine, from 30B 8-bit down to Llama 3.2 3B. Falling back to it is recorded, and a mandate can forbid it.

Guardian, deny by default

Pure Python; no model is its own control. Each payload is labeled, scanned and capped at 20 KB, then recorded byte for byte before it leaves.

A spend gate that cannot overrun

One ledger for the machine. Each call's worst cost is reserved before sending against a balance a person verified, with 20 % held back. US$0.96 spent so far, reconciled to the cent.

The false positive. Unbidden removed two type: ignore comments its mypy called unused. The team's CI was green, under Python versions Unbidden had not used, where those comments are needed. The patch would have broken their build. Now the Director reads the CI's verdict in every cycle, and every candidate is re-checked under the CI's newest interpreter. On the real patch, mypy reports 2 new errors, and the patch is rejected. On the frozen holdout it found no validated improvement in ten mature libraries, and it claimed none.

Try it

uv tool install git+https://github.com/satisfymath/unbidden-ai
echo 'MODEL_API_KEY=...' >> ~/.unbidden/.env
cd your-repo
unbidden init && unbidden doctor --fix
unbidden watch --once     # observe, decide, probe, experiment, propose
unbidden inbox            # what it found, most proven first
unbidden why <id>         # every decision and outbound payload behind it
unbidden spend            # what it cost, against the verified balance
