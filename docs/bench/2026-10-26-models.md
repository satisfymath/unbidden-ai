## Setup

MacBook Pro M5 Pro, 64 GB. Ollama with `muse-glimmer:30b-mlx` (nvfp4, ~19 GB). Meta Model API over the
internet. `think=low` reserves a 1024-token reasoning budget inside `max_tokens`. Spark 1.2 and Wonder show
US$ 0 because no price is configured for them; their token counts are real. The `fix_code` check runs the
model's file in an offline container.

## What we take from it

- **Local tier: Glimmer with `think=low`.** 25/25 correct, every answer valid on the first try, 7.7 s median
  per call. With thinking off it is twice as fast and still valid, but it failed the privacy rewrite 5/5: it
  kept every real name. The bridge therefore always runs with thinking on, and the egress gate (which
  would have blocked all five) stays the control that matters, not the model.
- **Frontier and code tiers: `muse-spark-1.3`.** 20/20 correct, all valid on the first try, 2.3 s median,
  about US$ 0.002 per call. Spark 1.2 matches it; Wonder is also correct but needed repairs on 4/5
  classification answers and is slower there.
- **Strict structured output and tools work on Meta's API** with `response_format: json_schema` and
  `tool_choice: auto` plus an instruction; no fallback to non-strict was needed in these runs.
