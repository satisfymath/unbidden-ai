# Level A benchmark: 12 repositories, 2026-10-27

The harness is `bench/repos.py`, and the list is `bench/repos/level-a.yaml`, with commits pinned and the holdout chosen
before any run. Each repository runs `init`, `map --no-model`, `scan`, `inbox` and `decide`, at its pinned commit, in
a fresh directory. No model is called; only package downloads leave, into the sandbox's dependency images.

## Reading the rows

- **Stack families.** Python and TypeScript/JavaScript are analyzed. Go, .NET, Java, Kotlin, Rust, PHP, Ruby, Dart
  and C++ are not (opentelemetry-demo, chatwoot's Ruby, immich's Dart). That is three families met: Python,
  JavaScript/TypeScript, and polyglot compose systems for the World Model only.
- **CI understood.** First run: 6 of 8 dev repositories. After the fixes: 7 of 8 dev, 3 of 4 holdout.
- **Analyzers complete.** In the dev set, lexical went from 4 to 6 of 7. docusaurus stays at 7 of 40: its packages
  must be built before they can be type-checked, which needs the repository's own build to run in the sandbox. That
  is not done yet, and the failure is reported as the environment, not as opportunities.
- **Why nothing ran.**
  - saleor needs a C compiler; the mandate does not allow Debian's archive.
  - immich depends on `.pnpmfile.cjs`, repository code pnpm would run during install with network access.
  - httpx installs itself from source (`-e .`).
  - fastify has no lockfile.

  Each reason is stated in the output.
- **Criterion (the Director, without running anything).**
  - full-stack-fastapi-template: 3 of 3 style findings declined (outside the CI's scope).
  - sqlmodel: nothing to do.
  - chatwoot: 82 lint findings would be acted on. 62 of them are `prettier/prettier`, likely an environment
    difference, but the CI is red at that commit, so the rule that declines environment-only findings cannot apply.
    This is a known weakness: the check is read per commit, not per job.
  - click: 4 type findings on a green CI would be acted on. They may be environment differences too, and the rule
    covers style only.

  Across the final dev run and the holdout there are 2,058 findings in 108 opportunity groups. Acting on every
  finding, the simple policy, would act on all 108. Unbidden declined 4 and would act on 104, 82 of them chatwoot's.
  On these repositories its criterion is barely stricter than the simple policy, and the weakness is named above.
- **Opportunities are not judged for quality here.** No ground truth exists for them. What is measured is whether
  analysis ran, what it found, and what the Director would do.
