# Unbidden

**Intelligence that doesn't wait for instructions.**

Unbidden is a proactive engineering agent you install like a CLI. It watches a repository, finds
improvements it can prove, measures them in an offline sandbox and proposes them as pull requests with
their evidence. Private context stays on your machine: Meta's Muse Glimmer reasons locally, and only
synthetic tasks approved by a policy gate reach Muse Spark and Muse Code.

Built at the Meta Global AI Developer Hackathon (October 26 – November 4, 2026). Work in progress.
